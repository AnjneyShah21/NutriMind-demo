# 🧠 NutriMind — Context-Aware Nutrition Coach

## 🚀 Overview

NutriMind is a **smart, context-aware nutrition assistant** that personalizes meal recommendations, tracks habits, and helps users achieve their health goals based on lifestyle, preferences, and daily patterns.

This project provides an **interactive dashboard experience** where users can:

* Build a personalized health profile
* Track meals and habits
* Get intelligent meal recommendations
* Monitor nutrition metrics and progress

---

## ✨ Features

### 🧩 1. Smart Onboarding

* Collects user data like:

  * Age
  * Weight
  * Goal (Weight Loss / Muscle Gain / Maintenance)
  * Diet preference
  * Activity level
  * Cooking time & budget
* Helps estimate personalized nutrition needs

---

### 📊 2. Interactive Dashboard

* Daily greeting with contextual insights
* Hydration & focus tracking
* Habit streak and consistency tracking
* Scheduled and logged meals

---

### 🍽️ 3. Meal Recommendation System

* Personalized meal suggestions
* Nutrition-based scoring
* Macro breakdown (Protein, Carbs, Fats)
* Context-based insights (budget, time, ingredients)

---

### 🧪 4. Detailed Meal Analysis

* Ingredients with adjustable servings
* Macro & micronutrient breakdown
* Nutrition score system
* Daily goal progress tracking

---

### 👤 5. Profile & Metrics

* Tracks:

  * Weight progress
  * Calorie intake
  * Protein intake
  * Water intake
  * BMI
* Visual progress indicators

---

### 📅 6. Meal History Tracking

* Daily meal logs
* Weekly tracking UI
* Streak and calorie summaries

---

## 🛠️ Tech Stack
